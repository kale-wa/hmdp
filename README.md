# 黑马点评（课程项目实践）

基于黑马程序员《Redis 实战》课程项目的学习实践，实现了本地生活类应用的核心后端功能。

## 技术栈

Spring Boot · MyBatis-Plus · MySQL · Redis · Redisson

## 已实现

- 短信登录 + JWT 双拦截器
- 商户缓存：封装 CacheClient，处理空值缓存（穿透）与逻辑过期（热点 Key）
- 优惠券秒杀：Redis 分布式锁 → Redisson 可重入锁 + 看门狗续期；Lua 脚本原子扣减库存；阻塞队列 + 线程池异步下单
- 达人探店、点赞、好友关注、附近商户（GEO）、用户签到（BitMap）

## 说明

课程跟练项目，代码用于学习与面试复盘，非原创业务系统。
